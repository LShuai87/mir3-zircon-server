# 角色主页正式版底图修复

基准为用户确认的1024×768窗口模式，沿用既有截图。此记录对应代码与资源的候选修复，尚未完成真实游戏和最终美术验收。

## 修改

此前角色四页共用底板把整块内区覆盖成近乎纯色，龙纹、属性底框及内边框同时丢失。本次保留共用底板，新增412×498的角色主页专用背景，仅在CharacterTab绘制，位于原人物预览和原控件下方。扩展装备、状态、修炼页继续使用原共用底板。

素材来自已选UI/2765.png。合成规则明确指定旧槽修补区、原纹理采样区、属性底框来源及目标位置；低频照明保留自修补区，细纹来自指定原图块，边缘仅混合RGB，Alpha仍为0/255。原人物预览、16装备格、属性数据、点击位置和操作事件继续使用既有实现。旧槽刻线覆盖区属于适配加工，不能声称复原了源图被槽位遮住的龙纹。

新图层安装前校验分页尺寸和零偏移；卸载、失败回退和销毁时解除绑定。非法尺寸不能替换已安装图层。新增角色源文件引用后，重新生成字段草稿、布局输入哈希和统一绑定合同。

[修复前后对照](character-before-after.png)：两侧均为实际客户端渲染的离线合成场景，角色、地图和物品属于测试数据，不是正式服截图。四分页及带物品角色页见scene/与item-regression/。
