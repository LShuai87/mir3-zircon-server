# 紧凑命令轮盘布局与点击归属

参考设置采用用户确认的1024×768窗口模式，沿用已有截图。附件实际1280×959单独记录；不据此推断DPI、精确客户区裁切或官方点击多边形。

本轮仅调整主界面命令区域：225×175原生龙纹外壳在225×202根画布内放置于(0,27)，七个轮盘按钮按截图相对关系收紧。八个图像按钮的绘制顺序从后到前为Spell、Quest、Mail、Group、Inventory、Config、Character、CashShop。透明像素穿透；可见重叠由最上层接收；隐藏上层可操作下层，禁用上层阻止动作下穿。候选期间锁定图像按钮层次，解绑恢复原Sort与控件顺序。

布局契约仅允许七个轮盘图像的边缘交叠，并要求按钮中心互不侵占；其他命令、模式文字与中性栏按钮继续禁止交叠。布局验证器增加透明命中、中心重叠、层次顺序和栏按钮重叠的负例。邮件/任务角标随按钮位置同步。

- Debug/Release构建通过；141项Python、70项基础、418项资源预检及288次GPU比较通过。
- HUD804项检查及812,688次合成GPU像素比较通过；窗口集成154,956项检查通过，含228个共享不透明坐标的单次点击、隐藏回落、禁用阻断和点击后层次稳定性验证。六分辨率仍扫描272,700个命令根坐标。
- 完整离线场景180项检查通过，覆盖三次真实构造、17帧、7次Device.Reset、六分辨率、场景重入和原聊天/输入状态保留。
- 92帧Zl重复构建一致；仅hud-command-frame变化，其余91帧、19组按钮素材与格子/组合契约不变。原生39,375个RGBA像素完全保留，顶部6,075个补边像素透明。独立BC1核对894,305个逻辑透明度像素，实际D3D9渲染95帧/组合、1,030,655个像素通过。

[1024×768离线渲染](scene/official-hud.png)使用合成角色和地图；[几何对照](geometry-study.png)展示参考、旧候选和紧凑候选。可见交叠按唯一坐标计228处，旧研究230是成对统计，计数口径不同。配套程序、11项依赖及Zl身份见[runtime-audit.json](runtime-audit.json)，命令与源码/证据哈希见[verification.json](verification.json)。

执行中曾用项目不支持的x86配置名，改为AnyCPU（项目实际PlatformTarget=x86）后双配置构建通过；早期Python运行受强制UTF-8子进程解码及旧绑定哈希影响，刷新绑定并使用系统默认解码后141项全部通过；初次GPU运行缺少独立解码oracle，生成后完整通过。未为这些执行前提修改产品逻辑。

Legacy仍为默认，RuntimeReady=false，五项G0与任务状态不变。相对截图适配不等于最终美术验收；真实登录、服务器操作、中文IME、最终画面和整包部署/回退继续待验。NPC卡片、按钮二级弹窗和显示设置维持既有范围；正式安装目录只读。本轮没有提交或推送代码。
