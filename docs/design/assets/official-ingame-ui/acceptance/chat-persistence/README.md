# 正式版聊天独立存储层验证

本轮完成独立聊天配置的存储层与验证，基准沿用已确认的 1024×768 窗口模式。游戏设置页不换肤，已有截图继续复用。

## 本轮变更

新增并编译 `GameUiChatStore`，以配置目录下的 `GameUiChat.OfficialV1.json` 保存聊天偏好。一个分辨率条目包括聊天组标识、坐标/尺寸、主组/浮动状态、按顺序排列的标签名、选中页和原有 12 位过滤/透明/提醒标志；其他分辨率的条目保留。显式空布局可保存，不自动变回默认标签。

读取校验结构、字段类型、版本、数量、范围及 UTF-8 编码。单次读写上限 1 MiB，最多六档分辨率、64 组、合计 256 标签。写入使用临时文件、刷盘和原子替换；失败保留旧文件及缓存，返回诊断。无效读取不改写文件。公开读取与保存均隔离可变对象。

目标框架中的 `InvalidDataException` 不继承 `IOException`，已单独加入可恢复异常范围。初始测试的组标识误写为 34 字符，修正为规范 32 字符；两次失败日志保留在报告中，不计入通过命令。

## 验证结果

- 存储层 4487 项检查、59 条证据记录通过：六档分辨率、全部 4096 种过滤组合、Unicode/转义名称、空布局、深拷贝、33 种非法保存、18 种损坏文档、编码错误及真实独占文件锁。
- 现有窗口集成 168514 项、聊天几何 940 项、完整离线场景 180 项检查通过；后者含 3 次真实构造、17 帧及 7 次显式 Device.Reset。
- Debug/Release 构建和检查用资源清单已生成；运行二进制与测试证据按哈希归档。详见 [结构化报告](verification.json)。

## 接入边界与下一步

**当前游戏界面尚未使用这个存储层。** 本轮没有修改 `GameScene.SaveChatTabs`、`LoadChatTabs`、“保存所有”按钮或启动/分辨率切换逻辑。现有“保存所有”仍走原生聊天数据库，不能据此认定正式版与 Legacy 聊天配置已经隔离。存储测试中的 Users.db 是字节哨兵，不能替代原生数据库集成验证。

后续依次接入：适配器捕获真实标签顺序和稳定组标识；正式版保存路由及失败反馈；显式加载和进入场景时恢复原生标签；仅在组标识和拓扑匹配时恢复对应分辨率几何；验证原生 Users.db 字节不变、草稿/HWND/历史保留、空布局和重入失败清理。存储由单个客户端界面会话拥有，不支持多个独立存储实例自动合并并发写入。

NPC 卡片及按钮后的弹窗保留原样式。任务计数仍为 7 完成/3 进行中/18 未开始；G0-2/3/4/5、真实登录重连/服务操作、装备槽语义及最终视觉验收未关闭。默认 Legacy，RuntimeReady=false、productionBindingAllowed=false、releaseAccepted=false。未提交、推送或部署，正式版安装目录保持只读。
