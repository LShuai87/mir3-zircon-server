# NPC 独立任务打开与服务并发布局

按用户确认的 1024×768 窗口基准继续实施。任务、NPC 主卡和二级弹窗保留原生样式。

## 本轮变更

- OfficialV1 窗口集订阅原任务窗口的 VisibilityApplied；回调发生在原显隐处理和置前操作之后。NPC 响应尚未完成时跳过，由响应末尾统一布局；窗口集恢复时解除同一实例的订阅。
- 任务窗口独立参与布局，保留完整原尺寸。此前将任务和服务拼成整体，会把任务高度扩展到整排服务宽度，1024×768 下无法保留所有标题和关闭区域。现在允许与包裹、仓库一样按窗口正文重叠，默认重排后标题与关闭按钮可访问；买卖等成对服务正文仍互不重叠。
- 测试通过真实 NPCObject 和 GameScene.NPCID 查找入口打开任务，没有手动置前或调用布局来修补结果。覆盖任务先开、响应先到、辅助窗口隐藏重开、任务重开和 Device.Reset。
- 场景重入检查比较打开 NPC 前实际加载的仓库位置与打开后位置，替代固定默认坐标。合成排列矩阵单独抑制配置写入，避免用批量测试动作改写共享的重入偏好样本。

## 验证结果

- NPC：33,049 项检查、3 次实际场景构造、773 次坐标点击、154 帧绘制、83 次设备重置；原 NPC 卡片 2,399,935 个像素一致，Legacy/OfficialV1/重入的原业务发包轨迹一致。
- 两次候选场景共 420 条布局记录：15 类响应、2 种打开顺序，6 个不同分辨率及回到 1024×768。28 条买卖组合记录均实际显示商品、出售和任务三个窗口；完整窗口边界、关闭按钮命中、成对服务无重叠及业务显隐保持均有检查。
- 窗口集成 165,921 项、完整场景 180 项、Python 172 项及 Debug/Release 构建通过；两个构建各有匹配的资源检查清单。
- 最终 NPC 证据为外部目录 npc-quest-open-20261108-v6。v5 是通过后的中间运行；检查渲染图发现其新建买卖页面没有配置商品，随后补足真实可见的买卖数据并以 v6 重新验证。

## 失败记录与限制

保留四次失败：v1 将正式版候选资源目录误作原生 Interface.Zl 来源，改用既有默认原生资源路径；v2 复现拼接任务高度导致的无解布局；v3、v4 在重入时仍断言仓库固定默认位置，改为核对实际加载位置是否被 NPC 打开流程覆写。详见 verification.json 的 failedAttempts，失败日志与外部证据均有哈希。

此轮验证默认重排结果。任意手动前景切换后的全窗口可达性、完整 17 窗口生命周期、显隐时偏好持久化语义、实服仓库和服务交易、字体形态、目标硬件、IME、设备丢失以及最终视觉和部署回退仍待验收。窗口正文重叠属于小分辨率下的明确行为，不声称所有正文同时无遮挡。
