# 场景启动接入与运行故障保护

本批将已有窗口候选接入启动会话和 GameScene，补齐失败回退、资源借用与输入故障保护。配置仍默认 Legacy，编译门禁 RuntimeReady=false；正式界面尚未开放，五项 G0 和任务状态不变。

## 行为

- Program 在消息循环期间提供固定启动会话。GameScene 在构造末尾、网络层赋值 User/业务数据前安装完整窗口集；只在准备正式布局时跳过四主窗口的旧布局加载。聊天先按原逻辑恢复，再安装候选外框。
- 包由应用会话持有，场景安装前登记借用。退出先解绑全部控件，再解除借用；仍被场景借用的包不能释放。布局存储目录从实际 Zircon.ini 配置路径取得，应用内重登复用同一个存储对象。
- 安装失败且候选完整解绑后，恢复原快捷栏尺寸、默认位置及四主窗口原设置；本进程后续场景继续使用 Legacy。回退不完整时保留场景和资源所有权，停止新操作并提示重启。
- 运行中界面故障只处理已登记的正式场景。清除持续移动和修饰键状态，拦截窗口、程序点击及原生文本框的用户输入，保留草稿、选择和 HWND。连接继续处理回包；已有发送队列不删除、不重放，新界面发起的操作被阻止。
- 原生通知面板提供退出入口，不依赖 D3D 绘制。DeviceLost/DeviceNotReset 保留原恢复路径；正式场景的其他 D3D 错误进入重启保护。
