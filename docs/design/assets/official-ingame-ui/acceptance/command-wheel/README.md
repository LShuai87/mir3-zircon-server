# 主界面命令轮盘原生底图适配

本次将右下角命令区的临时矩形边框替换为正式客户端的原生龙纹轮盘底图。基准为已确认的1024×768窗口模式，复用既有截图。默认仍为Legacy，RuntimeReady=false，五项G0及任务完成状态保持开放。

[前后对照](before-after.png)取自真实客户端的离线场景，左右均截取命令区(799,566,225,202)，展示时按最近邻放大2倍；不是正式版登录截图。完整候选画面见[1024×768截图](scene/official-reset-1024x768.png)。

素材明确选用UI[140]作适配：原图225×175，按边界连通的纯黑区域生成透明遮罩后，原位放入225×202透明画布，底部27行透明；不缩放、不裁剪。源库偏移(-112,-87)作为溯源元数据保留，输出偏移为(0,0)。构建器新增canvas变换，拒绝越界、裁切、非整数、布尔坐标及未知字段。[素材映射](source-map.json)记录全部参数。

既有截图不能唯一确定UI[140]与UI[1270]中的哪一张是正式版当前使用的源图；本次是明确的原生素材适配选择。当前九个原按钮、两个模式文字及其布局继续沿用已有合同，不把新增底图视为正式版按钮坐标和最终画面已验收。聊天内容、NPC卡片、二级弹窗及显示设置遵守此前范围约定。

[独立素材校验](native-art-verification.json)确认39,375个原生RGBA像素完全一致、6,075个补齐像素全透明，其余91帧PNG逐字节不变；两次素材树、Zl及准备清单逐文件一致。候选包保持92帧、19组按钮状态和457400字节；最新SHA256为29c580d3ccf3eef9196fa098e0f45ff7239b314085f520eaa81f2fa6562eb756。包路径、Debug/Release程序及依赖的哈希见[runtime-audit.json](runtime-audit.json)，此前清单保留为历史版本。

Debug/Release构建和141项Python测试通过。BC1核对894305个逻辑透明度像素；D3D9完成95帧/组合、1030655次像素比较。实际目录4069项、HUD803项及窗口集成9297项检查通过；窗口回归新增六种分辨率共272700个命中坐标比较，原控件外的装饰可穿透，隐藏/恢复角色按钮的命中符合预期。离线正常场景180项检查覆盖三次真实构造、六分辨率和场景重入；使用合成角色/地图，不连接服务器。
