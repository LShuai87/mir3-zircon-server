# 装备自动穿戴交互验证

基准为1024×768、窗口模式，复用已有截图，无需重复提供角色、包裹或显示设置截图。

本轮仅修改一份装备交互测试和五个测试脚本，未改生产逻辑。自动穿戴覆盖全部16个装备槽及护身符槽的DarkStone类型，分别验证右键和双击；左右手镯、戒指均验证原生选槽规则及双槽占满后替换右槽。

- 装备交互：20359项检查、2076次坐标命中；Legacy、Official及Official重新进入场景后的有序请求轨迹一致。
- 物品丢弃与背包操作：3775项检查；物品提示框：38968项检查。
- NPC原卡片兼容性：46129项检查、2399935个卡片像素一致，保持现有样式。
- 仓库场景：76项检查、243840个仓库像素一致。

穿戴测试在目标分页隐藏时发起操作，检查请求坐标、等待锁、防重复请求、拒绝后解锁、成功后的对象身份及其他15槽不变。卸下使用原生右键，回包在分页隐藏时处理；普通已穿戴装备双击保持原生不卸下行为。开发时曾误把双击卸下作为预期，测试在Legacy失败，现已纠正测试；三次失败尝试保留在验证记录中。

五个脚本补入共享场景切换和角色刷新测试源码，解决缺失依赖导致的编译失败，均已独立执行通过。沿用前轮Debug/Release运行文件，重新核对可执行文件、依赖及Zl包的哈希，本轮未重新构建运行文件。

已查看装备主页和扩展装备页的1024×768离线画面。重复药水图标来自测试夹具，不证明真实装备图标正确；黑色世界来自合成场景。全部证据、命令、失败记录和源码前后哈希见[验证记录](verification.json)。
