# 正式版主窗口候选接入验证

基准：1024×768。状态：开发候选；Legacy 仍为默认，未完成实机与发布验收。

## 本批内容

- 新增四窗口安装器：在原角色、包裹、原生横向十格快捷栏和小地图上绑定真实 88 帧包与编译期布局，保留原格子、事件、数据和窗口可见状态。
- 在 GameScene 增加内部候选消费入口；窗口尺寸改变时直接适配原控件，不进入旧聊天页重建流程。退出先解绑，再销毁控件；安装/缩放/解绑期间拒绝重入。
- 安装失败按逆序恢复；缩放异常锁定故障状态，防止再次套用。未完成的解绑保留资源所有权，允许重试，调用方须保持包存活。
- 恢复原 Legacy Settings 引用与真实兄弟控件顺序；清除额外角色页后重新计算原标签按钮位置。正式装备格启用时隐藏原空槽图案，解绑后恢复。
- 更新构建期角色映射及源文件摘要；运行时仍使用 C# 合同，不读取映射 JSON。

## 验证

- WindowSet 与实际 GameScene 方法路径：6,472 项检查通过，覆盖六种客户区尺寸、原控件引用、聊天历史/样式/输入 HWND/草稿/选择/频道、程序布局零写盘、重复/冲突所有者、跨线程调用、重入、末段安装失败、缩放异常锁定和退出解绑顺序。
- 实际 GameScene 测试仅绕过构造函数的世界初始化；调用真实尺寸属性、OnSizeChanged、事件和 Dispose。未创建联机世界，也不代表登录/重连验收。
- 角色页 17,248、属性 19,302、控件 4,584、组合 2,115、场景布局 1,464 项检查及 145 组真实控件布局通过；234 节点/109 交互节点合同和 12 个生成文件逐字节核对通过。
- 角色统一映射 5 组 Python 测试、生成后 --check、客户端 Debug/Release 和 diff --check 通过。Git 仅提示已有换行符转换。
- 两张 D3D9 探针验证原空槽绘制路径的隐藏/恢复；它们不构成完整场景的美术验收。

## 接入限制及下一步

- 本入口没有启动调用方，RuntimeReady=false；GameScene 默认仍创建旧快捷栏。完整候选启动路径必须先创建原生横向十格，再安装皮肤。
- HUD 与聊天容器尚未加入统一安装事务；经验填充素材、提示图标声明、操作入口语义和关闭按钮图像仍需核对。
- 真实中文 IME、D3D Reset、联机数据/发包、性能、组合视觉与发布回退尚未验收。五项 G0、任务完成数保持不变。
- NPC 卡片、按钮二级弹窗、游戏显示设置不换肤；复用用户此前 1024×768 截图，无重复采集要求。

可核对文件：verification.json、before.json、各命令日志、glyph-probes-final/。历史证据保留原值，当前源文件变更由 sourceChanges 衔接。
