# 独立商品商店接入与原 NPC 卡片回归

游戏设置采用用户确认的 **1024×768 窗口模式**，复用已有截图。附件像素尺寸单独记录，不推断 Windows DPI 或精确客户区边界。

独立 NPC 商品窗口使用 UI[511] 底图和原商品控件：344×438 固定窗口，列表区域 (24,48,280,324)，两列、行距54、列距140，每格138×52；物品命中格仍为36×36。商品名称、条件和价格限制为单行，长文字省略并保留完整提示；文本、颜色、选择事件、滚轮、双击购买、行会资金和原购买校验继续复用。购买按钮位于(164,400)，行会选项位于(24,376)。这些坐标是本项目的适配决定。

刷新商品先清除已释放的选择目标；解绑按当前商品集合恢复原排版，不重建商品或重发请求。安装/解绑失败保留恢复所有权，支持重试；修复恢复时滚动条滑块的原位置。NPC 交互卡片和按钮打开的数量/确认弹窗保留原样式及行为。
