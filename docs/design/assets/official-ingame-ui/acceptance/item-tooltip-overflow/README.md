## 实现

常规提示继续优先使用紧凑排版和分栏。超出分栏容量时，卡片限制在视口内，鼠标留在物品格上即可用滚轮上下阅读；底部显示滚动提示与百分比，保留全部原文字、字体和颜色。

超长单条文字直接裁绘到视口尺寸的纹理；原标签仅在溢出期间隐藏，不创建超高标签纹理。滚轮累计不足一格的刻度；滚动步长最多 48 像素且小于半个内容视口，前后位置没有阅读空隙。刷新和调整分辨率保留并夹紧位置；离开后重新悬停从顶部开始。窗口集合回退立即放行原滚轮事件，普通提示继续原分发。新纹理由原卡片子控件管理，刷新和退出释放。

原 BuildItemLabel 内容构造方法逐字保持，见 content-contract.json。NPC 卡片、按钮二级弹窗、设置与登录页面不在本次修改范围。92 帧资源包未变化。
