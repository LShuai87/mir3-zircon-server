# 换肤窗口标题边界修复

界面布局基准继续采用 **1024×768、窗口模式**。用户本次设置截图确认了此设置；上传图片本身是1280×960，布局尺寸不按上传图片的像素反推。角色、包裹复用已有截图，不要求重复采集设置页。

修复前，换肤标题仍自动撑宽并居中。长地图名实测占742×19像素，起点为(-297,1)，越出132×16标题区；短标题也超出标题区高度。现在标题固定在皮肤声明的矩形内，单行居中，超长显示省略号，&按原字符显示，原始文本、字体对象和非交互属性保留。

首次绑定皮肤时保存原生AutoSize、DrawFormat和固定尺寸；更换皮肤不覆盖原记录，撤销换肤时按当前文字恢复原设置。新增验证覆盖自动/固定尺寸、三轮切换、长短/空/换行标题、无标题皮肤、HasTitle及切回原界面后的文字更新。
