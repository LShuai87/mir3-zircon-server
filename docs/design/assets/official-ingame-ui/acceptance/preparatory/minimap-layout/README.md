# 小地图可选布局验证

以用户确认的1024×768为逻辑基准；现有截图直接复用。GameScene尚未调用此适配器，OfficialV1未启用。

- 候选窗口166×198，地图viewport为[11,21,150,152]，坐标文字为[24,177,118,16]，收起按钮为[146,2,20,16]。运行时使用编译C#布局，独立测试逐项核对JSON。
- 保留原Panel、地图Image、地图库、ScaleX/Y、标记字典和控件、拖动处理及原CloseButton事件。新增坐标文字不拦截鼠标；地图不足viewport或图像缺失时保留黑色底板。
- 接入顺序：创建原窗口，调用UseGameUiMiniMap(layout)，再安装尺寸及收起区域匹配的皮肤、加载窗口设置。活动布局固定尺寸；禁止在拖动/缩放中绑定，拒绝失效或已被替换的原控件。
- UseGameUiMiniMap(null)恢复捕获的皮肤、窗口尺寸、viewport、底板标记和关闭按钮状态，并按当前原标记重新居中。初次绑定及替换中的单次观察者异常均验证回退；窗口释放会解除原地图事件订阅。
- 通用DXWindow新增皮肤布局完成回调，防止皮肤切换恢复旧关闭按钮尺寸/可见性后覆盖小地图收起按钮。默认回调为空；原窗口、包裹和快捷栏回归通过。

538项控件检查通过，覆盖原控件/事件保留、坐标更新、地图订阅回调、缩放与拖动边界、皮肤切换、布局替换、异常恢复和释放。真实SlimDX D3D9绘制在两个位置、三种地图图像状态下通过206,040次像素比较，并验证绘制设备状态恢复。测试图采用合成纯色Zl，用于区分边框、地图、黑色底板和框外区域，不代表正式美术验收。

通用皮肤60项、通用GPU14项、控件读取26项、包裹6,349项、快捷栏6,157项及234节点布局合同回归通过；Debug/Release构建通过。12个生成文件重复生成一致，11类非法布局合同被拒绝。

尚未进行真实地图文件加载、联机切图、实际点击派发、正式素材效果、设置持久化、性能和游戏验收。UI-16及五项G0保持未完成；继续HUD、最终素材目录和GameScene接入。NPC交互卡片及按钮二级弹窗保留现有样式。
