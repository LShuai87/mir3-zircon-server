# 角色四页与装备格可选布局验证

本次只接入四个标签页和原有 16 个装备格。入口为 `CharacterDialog.UseGameUiEquipmentPages`；`GameScene` 尚未调用，完整正式版皮肤未启用，任务完成数和 G0 门槛不变。

- 以用户确认的 1024×768 为布局基准；候选角色窗口为 412×562，不改变游戏显示设置。
- 复用原“角色 / 状态 / 修炼”页，新增“扩展装备”页。常规 9 槽留在角色页；火把、药品、护符、鲜花、马护甲、徽章、盾牌共 7 槽移入扩展页。
- 原 16 个格子的对象、Slot、ItemGrid、GridType 和事件引用保留。容器位置相对窗口，页签/页面/装备矩形相对容器；当前候选容器原点为(0,0)，页内坐标从装备矩形扣除页面原点；可见页和点击目标一致。
- 固定页/页签尺寸不受窗口移动、标签文字变化及自动重排影响；原自动布局仍可使用。关闭此模式恢复格子父节点、位置和子节点顺序，释放扩展页；原选中页保留，扩展页选中时回到角色页。
- `GameUiCharacterEquipmentLayout.CreateOfficialCandidate` 使用编译后的坐标。测试脚本从 JSON 构建输入提取 4 个页签和 16 个格子，与真实客户端编译值比较，防止坐标漂移。运行时不读取 JSON。

验证结果：真实控件 12,173 项断言通过，包括六种窗口位置、25 次启用/替换/停用、页签点击、装备命中区域、恢复与释放；即时值回归 2,474 项、聊天回归 895 项通过，Debug / Release 构建通过。布局合同 231 项、11 类错误输入、生成 C# 编译/读回和 12 个产物重复生成一致性通过。

现有 57 项属性及标题/图标的完整排版和页面路由、预览枢轴与裁切、额外装备说明文字、最终页签美术及真实游戏行为尚未完成。当前格子检查不代替装备操作发包、实绘或游戏验收。
