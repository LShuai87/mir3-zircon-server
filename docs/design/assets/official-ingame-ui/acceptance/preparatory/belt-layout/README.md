# 快捷栏布局验证

以已确认的1024×768为逻辑基准，实现可选快捷栏适配。GameScene尚未调用，OfficialV1未启用。

- 候选窗口459×44；原10格整体移至[60,4,351,36]。保留每格36像素、35像素间距、0..9槽位、原链接对象、1..0键位标签与原点击事件。
- 客户区或窗口皮肤变化时，不再重建活动适配器持有的网格。物品引用、数量更新、选中/锁定状态及控件顺序继续由原实现处理。
- 默认`BeltDialog()`行为保留。正式皮肤接入需在启动时使用`BeltDialog(true)`创建原生横向10格；先调用`UseGameUiBelt(layout)`，再加载窗口设置及安装兼容皮肤。已有竖排、少于10格或失效控件在修改前拒绝。
- 停用`UseGameUiBelt(null)`时，由适配器在禁止重建期间恢复原皮肤、窗口大小、网格坐标和缩放标记；随后旧版手动缩放恢复原行为。窗口释放也清理适配状态。
- 非法替换保持当前布局；初次绑定和替换过程中发生单次观察者异常时，恢复原状态或上一活动布局。外部直接替换/销毁控件不属于支持的用法。

6,157项独立检查通过，覆盖默认/10格构造、旧版横竖缩放、两种原皮肤场景、各8轮启用/替换/停用、各6次窗口定位、客户区变化、两种快捷引用、数量刷新、非法绑定、异常恢复和释放。包裹6,349项回归、234节点布局合同及Debug/Release构建通过；12个生成文件重复生成一致，11类非法合同被拒绝。

真实快捷键使用、拖放发包、冷却渲染、重登与设置持久化、实际美术效果和性能尚未验收。UI-14及G0状态保持不变；继续HUD、小地图与最终皮肤接入。
