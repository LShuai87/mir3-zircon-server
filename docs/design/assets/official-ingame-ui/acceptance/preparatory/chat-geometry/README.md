# 聊天区域可选布局适配

已编译进客户端的按实例适配接口，尚未由 GameScene 启用，也不代表正式版皮肤已经接入。旧样式实例默认路径保持现有行为。

- `ChatTab.UseGameUiViewport` 在同一 TextPanel/ScrollBar 内调整内容矩形，复用消息对象、字体、颜色和频道 Tag；重排保留顶部消息及其内偏移，原先在底部时继续跟随底部。
- `ChatTextBox.UseGameUiInputLayout` 分别布置原频道按钮、输入框和设置按钮。保留中文草稿、选区、频道、私聊目标、最大长度、HWND 和活动控件引用；父层移动时同步隐藏原生输入框的位置，使用既有 DisplayArea 的实际字体高度。
- 两个接口均检查最小尺寸、非法参数和已销毁控件；禁用时恢复旧边距及按钮尺寸。滚动区实际高度至少51，避开现有滚动条拖动的零除边界。

1024×768提案：聊天主体574×83，内容矩形(4,3,548,76)，滚动条(554,3,16,76)；独立输入行574×22，频道(4,1,56,20)、输入(64,1,480,20)、设置(548,1,22,20)。主体以外的标签栏、边框和全局锚点由后续皮肤适配器安排。

验证通过：聊天895项、宿主回归1464项/145次真实控件布局、窗口皮肤60项、图片/按钮26项、布局存储35项；Client Debug/Release构建通过。详见[verification.json](verification.json)。复现：`powershell -NoProfile -File tests/Run-GameUiChatLayoutTests.ps1`（先构建Client Debug）。

限制：测试使用隐藏窗口，不等于真实中文输入法组合态/候选窗、快捷键路由、过滤或网络发包验收。最终设置按钮应绑定图标并隐藏原文字，22像素宽不直接展示旧文字；标签栏、滚动条美术和GameScene接入仍未完成。NPC卡片、按钮打开的二级弹窗、游戏显示设置不换肤。
