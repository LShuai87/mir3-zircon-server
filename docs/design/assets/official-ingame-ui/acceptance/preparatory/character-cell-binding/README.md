# 角色装备格底框绑定验证

记录日期：2026-11-08。沿用1024×768基准及现有截图。本批将独立36×36装备格底框绑定到原16个DXItemCell；没有增加格子、子控件或鼠标命中面。

CharacterDialog.UseGameUiEquipmentCellFrame接收借用的MirLibrary及帧索引。必须先安装四页装备布局；索引有效、尺寸36×36、offset为0且16格仍属于对应页面后，才整体绑定。失败替换保留现有绑定；重复调用只更新帧，不叠加事件。底框在原BeforeDraw事件之后、物品/标记/选中绘制之前呈现，沿用现有场景与父级裁剪。旧空槽提示事件及固定/选中边线保留，底框不改变它们的开关。

清除底框、关闭四页布局或销毁角色窗口时均解除本批订阅，保留其他事件；不销毁借用的资源库。渲染恢复原混合、透明度状态；包的加载、生命周期与最终场景接线仍由后续统一入口负责。

验证结果：

- Debug及Release构建通过。
- 17,249项角色分页/装备格断言通过，覆盖原16格、数据与点击事件、四页与六种窗口位置、25轮安装/替换/清除、错误资源拒绝、外部事件保留及销毁。
- 实际D3D9绘制36组画面，四页×三种裁剪位置×空槽/物品/选中三种状态；4,741,812次像素比较，最大RGB误差0。两个不同底框帧交替，验证替换、物品居中及选中覆盖顺序；状态与修炼页没有残留格框。
- 底框绘制在非默认混合与透明度下恢复设备状态；既有角色组合套件2,115项检查通过。

GPU使用合成BC1图案及真实原格子，输出在E:/workspace/mir3-ui-work/character-cell-binding-d3d-20261108-v3。原有固定/选中边线由Line绘制，其边缘2至3像素区域未纳入本批像素比较；本批不宣称验证了边线形状或正式人物预览。上一批88帧真实素材及压缩结果保持原样，见[角色底图与素材报告](../character-surfaces/README.md)。

前三次运行的失败均来自测试夹具：错误假定原BeforeDraw数量固定；ItemInfo属性写入要求MirDB会话；把原固定边线误计为底框像素。均已修正，原失败日志作为诊断保留，不作为通过命令登记。完整命令、源码迁移与最终日志见[verification.json](verification.json)，修改前119项已登记源码见[before.json](before.json)。
