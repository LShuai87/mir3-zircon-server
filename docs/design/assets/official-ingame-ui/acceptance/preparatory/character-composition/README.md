# 角色页组合布局验证

在既有四页、57项属性及原控件适配器上组合四项即时值，并接入人物预览锚点与裁剪。仍为可选API，GameScene未调用，OfficialV1未启用。

- 编译坐标相对角色窗口：预览框[60,138,134,193]、锚点[127,323]；等级/经验/生命/魔法值使用[310,98/122/146/170,86,20]。运行期不读取JSON。
- 四项数值复用MainPanel原标签的文本和提示更新来源；页面移动或容器偏移后保持窗口坐标，不重复创建标签或订阅。
- 预览仍使用原人物、装备染色和特效选择路径；启用后对Image、Overlay与特效按预览框、角色页、祖先和场景边界裁剪，无缩放。停用时继续原绘制调用。
- 页面、属性、说明控件和组合的替换前检查交叉重叠；非法输入保留活动绑定。停用任一前置布局、释放来源或窗口时清理组合。

2,115项组合断言通过，包含300个裁剪用例、6次窗口定位、8轮启用/替换/停用和容器原点偏移。原控件4,584项、属性19,302项、分页12,173项、即时值2,474项回归及Debug/Release构建通过；布局232节点、109热区、60项定位及12文件重复生成一致性通过。

**尚未验收实际预览渲染**，最终美术、代表性装备/特效显示、包裹/HUD/小地图接入、输入法、性能及全游戏验收仍待完成。基准为用户确认的1024×768，复用已有截图；NPC交互卡片和二级弹窗保持原样。
