# HUD 可选布局验证

按用户确认的1024×768逻辑基准实现。复用已有截图，不要求调整显示设置。适配器尚未由GameScene调用，OfficialV1保持关闭。

- 四个分区：血球225×202、按钮225×202、即时属性574×16、经验574×8。分区是主面板的同级控件，位置由场景协调器设置。运行时使用编译C#布局；JSON仅供构建和独立对照。
- 复用26个原控件及9个原按钮事件。聊天、人物预览、包裹等适配由各自模块负责；NPC卡片和按钮二级弹窗保留现有样式。
- 生命/魔法保留原数值更新来源，采用底部向上裁剪；经验保留原等级经验表比例及左侧向右裁剪。数值标签保持原Text，紧凑区域使用省略显示和完整Hint；经验标签隐藏并沿用原经验条的当前值/上限Hint。
- 先调用UseGameUiHud(layout)，再绑定尺寸匹配的分区、按钮四态和三个填充图像，最后由场景协调器定位四个根控件。替换布局不重建原控件或根分区；拒绝移动中、尺寸不符、原对象被替换的输入。
- 主面板Visible与Enabled同步到四个分区，场景禁用继续生效；填充位于数值标签下方。隐藏的旧装饰不参与新布局绘制。
- UseGameUiHud(null)恢复原父子关系、绘制顺序、坐标、图像、四态、混合/透明度/偏移标记和标签自适应。保留实时数值；角色魔法/道术标题按当前职业可见性恢复。主面板换父级、根分区换父级或任一新增分区/填充销毁时先恢复原控件。

788项检查通过，覆盖主控件/根尺寸与JSON一致、六处坐标、三种语言区域、真实HP/MP/XP setter、越界数值、提示、原事件引用、同时任务提醒、反复绑定/停用、一次观察者异常恢复和外部移除/销毁。经验填充沿用Globals.ExperienceList[level]，文字/Hint沿用User.MaxExperience；分别验证，未改变原有两种来源。

真实SlimDX D3D9 GPU验证通过72帧、812,688次像素比较：三种尺寸、八个比例、普通位置/父控件裁剪/场景右下边缘三种情形。合成Zl的4×4彩色块使错误的源像素偏移可被检测；另检验混合与透明度状态恢复。此证据只证明裁剪和状态行为，不代表正式美术或游戏内验收。

角色即时值2,474项、通用窗口皮肤60项、通用GPU14项、控件读取26项及234节点布局合同回归通过；Debug/Release及差异空白检查通过。

仍待集成：三个提醒图标沿用原2px内边距和双任务提醒分离规则；它们尚未与JSON的14×14装饰声明逐项对齐，未计入26个主控件几何一致结果。紧凑即时属性的最终可见标题、正式素材、场景接入、鼠标派发/弹窗动作、联网、IME、性能和包体回退均未验收。本批不关闭UI-06、UI-12或G0，不声明游戏已替换完成。
