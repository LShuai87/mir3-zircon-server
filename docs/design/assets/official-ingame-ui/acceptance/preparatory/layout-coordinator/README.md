# 统一布局协调器准备结果（UI-11）

已实现独立的 `GameUiLayoutCoordinator`，并编入客户端；尚未连接 GameScene，不改变当前画面或聊天行为。UI-11 保持未开始，A14/A15 保持未执行。

## 已实现

- 固定执行顺序：进入写入抑制作用域 → 首次恢复聊天实例 → 全部窗口应用皮肤 → 收集全部布局请求并验证几何 → 应用全部位置 → NPC 服务置顶 → 恢复模态/提示层级 → 刷新一次输入框矩形。失败时释放作用域和重入标志。
- 区分整个客户区与 safeRect；支持九种锚点、偏移、已保存位置和可调整视口。固定内容不按保存的尺寸缩放；损坏或不可用记录回默认，最后约束到可用区域。
- 超出可用区域的内容仅在对应方向声明已实现滚动时允许缩小视口，并保留完整内容尺寸；最低可用尺寸仍放不下时明确报错，不静默隐藏内容。
- NPC 默认按上下 → 左右 → 叠放选择组合；两窗已有独立且互不遮挡的有效保存位置时保留。叠放保留主卡标题区；主卡与服务窗同时留在 safeRect 内。
- 同步重入返回 `false`，不再次进入写入作用域；每个协调器只恢复一次聊天实例。协调器接口不接收聊天消息、频道数据或发包入口。
- 校验器按顺序重放补充报告的源文件哈希迁移，再核对最终磁盘文件；旧报告保留原哈希。遗漏迁移、错误前置哈希、重复条目或快照不匹配均拒绝。

## 已验证

[验证记录](verification.json)及同目录日志记录实际执行结果：

- 六分辨率、九锚点、2,400 组固定种子随机位置，含整数极值偏移；共 25,303 个断言（包含作用域和调用顺序检查）。
- 保存位置/尺寸恢复及回退、三种 NPC 组合、滚动视口、失败前几何校验、重入抑制、失败重试和线程限制。
- 7 项历史证据迁移回归；原布局 35 项回归；客户端 Debug/Release 构建通过。

## 接入约束

1. 最终素材和布局冻结后，才在场景中提供宿主及窗口适配器；本次模拟尺寸不能作为最终坐标。
2. 宿主抑制必须覆盖作用域期间新建的窗口；窗口只有实现对应方向滚动/裁剪后才能声明滚动能力。
3. 场景若在当前布局回调期间收到不同分辨率或 safeRect 请求，须在本轮结束后重新调度；`false` 表示本次请求没有执行。
4. 宿主保持业务显隐和消息实例，分别适配消息列表视口与输入控件。列表沿用当前项目样式，不引入正式版 15 级发言限制；依据[聊天范围决定](../../reference/chat-scope-decision.json)。
5. 实际滚动、关闭/操作入口、输入法/焦点、模态命中、NPC 服务行为仍需在项目客户端验收；本报告不将几何模拟结果等同于真实交互通过。
