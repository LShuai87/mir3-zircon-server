# 场景布局宿主：真实控件接入准备

本轮实现已编译进客户端，但尚未连接 `GameScene` 的构造、resize 和聊天重置路径；默认界面仍走原实现，未关闭 G0，也不把 UI-11 标为完成。

- `GameUiSceneLayoutHost` 将统一布局结果应用到现有根级控件。皮肤和坐标由后续编译目录提供；不猜测最终资源或矩形。
- 窗口布局读写路由到独立 OfficialV1 存储；第一次恢复可见性，后续布局只恢复几何。按场景抑制自动重排写入，覆盖既有窗口、过程中新增窗口、嵌套和异常退出；其他场景照常处理。
- 聊天沿用原 `ChatTab`、标签和消息对象。重排保留顶部消息锚点或底部跟随，刷新原生输入框坐标；单行框的实际高度采用既有 `DisplayArea`，不强行改变字体或显示设置。
- 重复 ID、同一控件重复注册、跨场景控件、重复持久化窗口类型和没有视口实现的滚动声明会被拒绝。

实际验证：六种分辨率 145 次真实控件布局、1,464 项断言；协调器 25,303 项、窗口皮肤 60 项、图片/按钮 26 项、布局存储 35 项回归通过。Debug/Release 客户端及 ImageManager Debug 构建通过。详见 [verification.json](verification.json) 中的命令、日志及哈希。

限制：原生输入测试使用隐藏窗口，只证明句柄、草稿、选区和活动控件引用保持；真实中文输入法候选/组合态、聊天过滤与发包、正式皮肤点击和视觉验收仍待游戏接入后验证。当前不要求用户重复截图、登录或发送聊天。
