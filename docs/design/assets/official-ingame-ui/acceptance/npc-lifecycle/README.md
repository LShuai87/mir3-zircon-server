# NPC 生命周期与选择清理回归

基准：1024×768 窗口模式；复用现有截图。此报告只完成本轮生命周期修复与隔离回归，未通过发布验收。

## 修复

首饰重置和武器洗练缺少隐藏时的关联清理。旧运行程序分别在“离开主对话”和“关闭主对话”后复现物品双向关联残留，日志为 npc-baseline-v2.log、npc-baseline-v3.log。问题在 Legacy 路径也存在。

在两个原窗口的 OnIsVisibleChanged 中调用现有 ClearLinks：首饰目标格一个，武器模板及材料格共七个。隐藏、关闭或替换服务后解除两端关联，重开要求重新选择。未增加交易请求；原生样式、格位、容量和服务按钮流程保持。

## 已验证

- NPC 套件：46,129 项检查，3 个真实 GameScene，1,472 次坐标操作，157 帧，83 次设备重置；2,399,935 个原生 NPC 主卡像素一致。
- Legacy、Official、Official 再进入的有序业务轨迹一致。
- 每场景覆盖 15 类响应 × 5 条路径：关闭按钮、离开选项、服务器关闭、当前 NPC ObjectRemove、替换普通页面；共 225 条矩阵记录。实际移除已登记的 NPC 对象，同时验证无关对象移除不会关闭当前 NPC。
- 两种关联服务覆盖 30 个关闭/重开场景，检查双向解除、不锁定物品、不额外发交易包；保留独立任务卡的原生生命周期。
- 每场景再以真实坐标关闭 100 次，共 300 次，检查没有孤立服务窗或重复关闭包。
- 对真实解码的 TimedOut 断线包，验证原生返回登录提示及连接状态；随后直接销毁仍有物品选择的场景，检查 17 个原窗口、已捕获子控件、模态框和全局输入引用释放。以上三种样式/进入顺序均通过。
- 窗口集成 165,921 项、完整场景 180 项通过；Debug/Release 编译及匹配资源清单已归档。

## 证据与边界

verification.json 绑定源码前后哈希、命令回执、测试运行二进制和外部证据；source-before 保留修改前源码。首次测试有局部变量声明遗漏，编译失败日志已保留；修正后在旧程序上分别复现两个缺陷，再构建修复程序并通过完整套件。

断线测试未点击提示框进入 LoginScene，未验证真实 socket 断开或重连。其余服务仍使用前序交互测试覆盖；本轮新增选择探针只针对首饰重置和武器洗练。显隐偏好持久化、实服存取与服务交易、角色字段/装备槽语义、最终视觉和设备实机验收仍待完成。

NPC 主卡、任务卡及服务/确认弹窗保留原样式。默认 Legacy；RuntimeReady=false、productionBindingAllowed=false、releaseAccepted=false。任务仍为 7 完成 / 3 进行中 / 18 未开始；未提交、推送或部署。
