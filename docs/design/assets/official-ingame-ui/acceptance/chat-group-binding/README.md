# 聊天外框与原生输入行接入

采用用户确认的 1024×768 基准，复用既有截图和显示设置。本批将原生聊天组和原生输入行加入既有窗口集的安装、布局和回退事务。

- 主聊天组位于 (225,630)，尺寸 574×106；输入行位于 (225,738)，尺寸 574×22。宽屏按实际客户区水平居中。
- 保留原 ChatTab、标签按钮、消息、字体、颜色、频道过滤、草稿、选区、焦点和输入 HWND；不重建聊天页。12 个标签溢出时用原生按钮翻页，选中标签自动可见。
- 历史内容区相对聊天组为 (4,26,548,76)，滚动条为 (554,26,16,76)；标签区高 24，最小聊天组为 106×81，避免原生滚动条除数为零。
- 原生标签可拖出新窗口、合并、改名和关闭；新增组按拓扑事件接入。主窗口移动或缩放后保留浮动位置，客户区变小时限制在可见范围内。
- 透明度沿用原选项；选为透明时隐藏装饰外框，聊天消息继续使用原样式。原“设置”按钮在窄输入行显示“设”，处理事件及弹窗样式保留，卸载时恢复标签。
- 卸载时恢复原控件几何和原生背景，保留用户后来形成的标签分组/顺序及消息。移除翻页按钮、外框和全局拓扑订阅；末段失败回退整个窗口集。单次回退观察者异常可以重试。

验证通过：聊天 940 项、窗口集成 9,202 项、角色四页 17,248 项、角色动作控件 4,584 项、角色绑定合同 5 项、六分辨率布局与目录检查、Debug/Release 构建和源码格式检查。窗口集成覆盖原生拖出/放下/合并、浮动窗口、动态组、透明切换、输入状态、完整事务故障回退及退出销毁。

候选包保持 91 帧。GPU 输出仍只有既有装备槽旧图形抑制两张探针；本批没有完整聊天/HUD 渲染、最终美术、实机、网络发包、真实 IME 组合输入或设备 Reset 的验收结论。Legacy 默认、RuntimeReady=false、五项 G0 与任务状态保持，正式皮肤尚无启动启用调用方。
