# 包裹金币框与负重条官方素材对齐（2026-11-10）

保留 7×7、49 格包裹和现有标题、格子、底部按钮及方形关闭按钮。

金币展示框使用本地官方 UI[124] 的深色纹理和细凹边。源图 80×20，通过保留 2px 边角的九宫格适配到现有 209×20 展示区域，为大额金币保留空间。金币文本继续使用原生 GoldLabel，保留千位分隔、实时数值和原点击逻辑；新增背景在文字之前绘制，不接管输入。

负重条保留窗口图集的 124×9 凹槽，普通填充使用官方 UI[121]，超重填充使用 UI[253]。两者均为原生 120×6，位于凹槽内 (2,2)，按服务端数值计算比例并裁切纹理，避免部分进度压缩渐变。超重同时改变负重标题颜色，悬停提示仍显示实际值与上限。空值、零容量和满值继续使用原有边界处理。

资源嵌入客户端，无需运行时读取官方安装目录。独立来源记录见 build/game-ui/inventory-gold-source.json 和 inventory-weight-source.json，记录源文件哈希、资源索引及原图哈希。Prepare-InventoryButtonArt.py 可复现普通按钮、关闭按钮、金币框和负重条四组资源。切回 Legacy 会释放新增贴图控件并恢复原生样式。
