# 物品丢弃与包裹按钮回归

本轮修复包裹按钮打开的原有弹窗超出屏幕的问题，并补齐鼠标按住移动/释放、丢弃、金币确认及快捷栏解除链接的离线坐标回归。参考仍为用户确认的1024×768窗口模式；复用已有截图。未关闭任何G0或游戏内验收项。

## 修复

`InventoryDialog.OpenInventoryPopup`统一打开远程出售、拆解和爆率查询窗口：保留原窗口对象、尺寸、控件、样式和事件；原打开位置能完整显示时保持原位，否则将X/Y限制在游戏视口内。

| 1024×768的爆率查询窗口 | 原坐标/尺寸 | 修复后坐标/尺寸 |
| --- | --- | --- |
| Legacy | (500,377),368×396；底部超出5像素 | (500,372),368×396 |
| OfficialV1 | (500,412),368×396；底部超出40像素 | (500,372),368×396 |

修复前的坐标观测见`before-location-fix.log`，失败断言及截图见`before-fix/`。该日志来自修复前的探测版本，最终套件恢复完整视口断言。800×600下同时覆盖横向、纵向越界。NPC卡片与按钮弹窗仍不换肤。

## 证据与边界

`verification.json`记录源码转换、测试程序依赖、日志及证据哈希。两种Shell均保存断言、坐标、指标和三场景语义记录；仓库保存PowerShell 7的27张代表性最终截图及2张修复前截图。每种Shell的全部63张最终截图仍在外部工作目录`E:/workspace/mir3-ui-work/item-drops-20261108-v1/`的对应`final-*`子目录。

测试使用真实GameScene/UserObject/D3D与只读资源、合成地图/物品及无Socket队列，回包注入原处理函数。正式版目录未写入；没有真实登录、重登、服务器交易、实机IME或最终素材视觉验收。装备图标仍为夹具图，不能据此判断最终美术。仅验证支持范围内且可容纳弹窗的六种分辨率，不声明任意小视口适配或零缺陷。
