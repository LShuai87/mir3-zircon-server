# 包裹凹槽格子、整理按钮贴图与方形关闭按钮（2026-11-10）

保持 7×7、49 格包裹。显示用户参考图中的深色凹槽、金棕色倒角格子；底部三个按钮使用本地官方最新版“整理”的按钮底图；包裹关闭按钮使用官方红棕色方形叉号。

## 实现与来源

原先 DXItemGrid 的不透明背景和直线网格覆盖了窗口图集中已有的凹槽格子。Official UI 模式关闭该网格背景和边框，保留 49 个原 DXItemCell 及其选中、锁定、悬停、拖拽、数据和链接逻辑。

三个底部按钮使用官方 UI[30..33] 的普通、悬停、按下、禁用贴图，保留“远程出售 / 远程拆解 / 爆率查询”的原文字和回调。保留 3px 边角后适配原 78×22 区域。

包裹关闭按钮使用官方 UI[40..43] 的四态方形叉号，同样保留边角后适配 18×18 标题栏区域。新增绘图子控件不接管输入，原关闭回调继续控制可见性及物品链接清理。

两组贴图嵌入客户端程序集，不要求运行时访问官方安装目录。Prepare-InventoryButtonArt.py 配合 inventory-button-source.json / inventory-close-source.json 可复现资源并校验源文件哈希。源目录仅读取，未改动历史全局资源清单。

切回 Legacy 时恢复原格子背景/边框、底部按钮、关闭按钮的样式和尺寸，移除新增绘图子控件。保留此前的“包裹”标题、负重进度条与金币格式。
