# NPC 服务窗口统一定位入口

本轮对应 UI-25 的定位入口准备工作，参考1024×768窗口模式。NPC主卡片与二级服务窗口均沿用原样式。默认Legacy，RuntimeReady=false，productionBindingAllowed=false，releaseAccepted=false；未提交、部署或发布。

## 实现

- NPCResponse中的15处服务Location写入移到ApplyServiceLocations；先完成显隐、NewGoods和RefreshList，再统一定位。
- OfficialV1场景缩放复用该入口，读取当前卡片与服务尺寸。只移动可见服务，不修改显隐、尺寸、控件、内容、按钮事件或报文。
- 保留买卖分列、伙伴双窗口及MasterRefine借用Refine宽度等原规则。任务窗口仍由独立报文流程处理。
- 无新增事件订阅、控件重建或原服务皮肤安装。隐藏服务的位置不再因其他NPC响应被改写。
