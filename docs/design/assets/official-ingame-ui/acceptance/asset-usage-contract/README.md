## 校验与运行方式

[校验工具](../../../../../../build/game-ui/Validate-OfficialUiAssets.py)将用途清单与当前场景入口的显式帧调用及按钮字典相互核对，检查唯一归属、所有包内帧的分类、源库/索引/PNG 哈希、逻辑尺寸/BC1 对齐、offset/pivot、二值透明、Normal 混合及四态 tint 规则。对工具无法识别的新表达式直接报错，要求同步审查扫描规则；这是当前入口的保守静态核对，不替代 C# 执行证明。

从仓库根目录运行：

```powershell
python build/game-ui/Validate-OfficialUiAssets.py --artifacts E:/workspace/mir3-ui-work/npc-shop-assets-20261108-v1
python -m unittest discover -s tests/game-ui -p 'test_*.py'
```

`--artifacts` 校验现有隔离目录中的30张源PNG、93张输出PNG和93个Zl数据块，不重新压缩、不写正式版目录。输出报告使用新的 `--output` 文件路径；已存在时拒绝覆盖。只检查源码/JSON时可省略 `--artifacts`，此时输出明确标记未验证磁盘素材。

增加 `--require-complete` 时，当前候选应返回失败：仓库底板与最终视觉/控件覆盖审定尚未完成。工具刻意保留仓库缺项保护，后续冻结底板时须同时审查该保护及用途清单。

## 本次证据及剩余门槛

[最终审计](asset-audit-final.json)验证30张源图、93张PNG的文件及RGBA哈希、93帧二值透明和93个BC1块；确认4,262个不透明纯黑像素保留，154,387个透明像素的RGB为零。BC1为有损压缩，不将哈希一致解释成原PNG与Zl色值无损一致。此次没有运行GPU对照。

[失败控制](failure-controls.log)包含18项测试，覆盖遗漏仓库、误报未接入素材、调换源帧/按钮态、改变混合/tint、失效控件锚点、未识别的动态调用、扩大NPC范围、提前启用及篡改BC1块。全套Python结果见[测试日志](python-suite.log)。

独立仓库的底板仍没有唯一角色、来源和切片/组合规则；原字段/动作复用覆盖及最终PNG/Zl实绘仍需审定。UI-05继续进行中，G0-2/G0-5未关闭；布局与动作映射G0-3/G0-4也未关闭。Legacy仍为默认，RuntimeReady与productionBindingAllowed保持false，没有发布验收或零缺陷结论。

首两次工具试运行分别误按sourceRole查找重命名合成输出、误把普通态的null当作字符串normal，已按现有格式修正。日志保存在asset-audit-attempt1.log和asset-audit-attempt2.log，不列为通过命令。源文件与证据哈希见[验证清单](verification.json)。

任务清单复验曾将输出重定向到已被验证清单引用的同一日志，导致读取时日志被截断。已保留错误日志，按事先记录的哈希恢复逐字节相同的成功输出，并将复验输出改到独立文件；此错误不列为通过命令。
