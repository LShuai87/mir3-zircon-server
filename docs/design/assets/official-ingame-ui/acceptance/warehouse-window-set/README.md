## 发现并修复的问题

最初仓库纵向偏移为 4，会在修理流程自动显示仓库时遮挡主 NPC 的关闭按钮。真实坐标命中回归捕获了此问题；默认纵向偏移调整为 86 后，NPC 关闭按钮命中恢复，全部原 NPC 回归通过。这仅验证已覆盖的默认布局和操作序列；长卡片、拖动后的组合拓扑仍须专项验收。

测试本身的编译访问、保存文件假设、PowerShell 哈希命令环境及生成合同过期问题均已修正并重新执行。失败输出保留在本目录，未列为通过命令；详情见 [verification.json](verification.json) 的 `failedAttempts`。
