# 角色装备槽位置修正

基准为1024×768窗口模式，复用既有正式版截图。此项修正属于当前实施候选，不代表真实游戏或最终画面验收。

实施方案6.2规定头盔位于人物上方、鞋位于左下方。之前两格虽通过边界和不重叠检查，实际位置仍不符合该语义。本次将头盔格从(16,96)移到(110,96)，鞋格从(110,340)移到(16,340)。坐标相对角色窗口，单位为逻辑像素；均为36×36，图标、可见框和命中区同步。预览框为(60,138,134,193)，两格均在其外部。

仅调整既有Grid[2]与Grid[9]的布局，槽位编号、物品数组、控件实例、动作和发包路径沿用原实现。四分页、9+7装备分配及其他控件保持原合同。复用原92帧Zl，绘制格框随控件位置移动，无需重新合成素材。
