用户确认游戏设置为 1024×768、窗口模式。沿用既有参考图，不要求重复截图或采集显示设置。

## 实现

- 新增每提示实例的布局，仅在场景 OfficialV1 窗口集合成功安装后启用；保留 Legacy 默认值与旧提示外观。
- 深色背景、细边框、6 像素内边距，靠近视口边缘保留 4 像素。颜色和透明度是参考图适配值，未宣称来自正式版原始参数。
- 原物品内容构造方法整体保留，仅更名为 BuildItemLabel，由原 CreateItemLabel 入口调用；原数据、使用条件、品质色、定时刷新、格子事件均沿用。
- 长文本按原字体换行，连续英文启用 GDI TextBoxControl 规则；属性超高时按阅读顺序纵向分栏。没有省略号、字段删减或字体缩小。
- 窗口集合回退后下一处理帧重建旧版提示；场景退出和物品格离开继续释放提示。NPC 卡片、设置窗口和按钮二级弹窗不换肤。

## 边界

极端文本或属性总量超过整个视口容量时，目前保留全部字段并退回超高卡片，不保证所有内容同时可读。该情况需要另行确定交互方案，不能据此关闭 UI-19。离线样本也不能替代真实服务器、中文 IME 与最终画面验收。

Legacy 默认、RuntimeReady=false；五个 G0 门禁及任务状态保持原值。本报告是增量候选验证，不是正式验收，也不承诺零缺陷。历史实施方案未改动。
