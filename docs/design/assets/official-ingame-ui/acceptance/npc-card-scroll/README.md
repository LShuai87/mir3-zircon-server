# NPC 长正文真实滚动与有界纹理

本轮按已确认的 1024×768 窗口基准继续实施，不补采截图，不更换设置页、NPC 外框/正文/选项/关闭按钮样式和二级弹窗。

## 实现

- OfficialV1 主卡正文超出 HUD 上方空间时显示原生滚动条；正文纹理只分配可见区域大小，按可见段落绘制，保留完整 PageText.Text。
- 正文和原选项标签使用相同滚动偏移；滚轮、原生上下箭头和拖动后的鼠标目标立即刷新。关闭按钮固定，正文滚动不重建标签或触发报文。
- 每个原选项共用 1 秒间隔，间隔存于页面而非标签闭包，缩放重排不会重置；页面替换清空间隔并释放旧命中区域，ButtonID=0 保持原关闭流程。
- 超过 9,999px 的选项位置不再被测量高度截断；长正文尾项从段落起点测量并复用段落累计高度。短卡片恢复原内边距与紧凑高度。
- DXLabel 新增两个默认等价的受保护绘制扩展点，其余标签默认绘制不变。旧 NPC 样式与业务处理继续复用。

## 验证

最终 NPC 回归 17,611 项、733 次真实坐标命中、68 帧、47 次设备重置，短卡片 2,399,935 像素一致。900 行正文验证超过 10,000px 的末项、跨行操作 ID、原生上下箭头、滚动/缩放后的间隔、六分辨率、设备重置及短页替换。正文纹理在部分行偏移和底部各与独立全文绘制逐像素比较，两次 Official 场景共 4 次一致。

窗口集成 165,921 项、完整场景 180 项（17 帧、7 次重置、690,512 像素一致）、172 项 Python 测试及 Debug/Release 编译通过。最终运行时与两份检查清单均保存；完整 94 帧 Zl 包不变。

早期失败原样保留：首轮测试访问受保护成员导致编译失败；第二轮旧定位算法耗时过长，确认进程后终止；第三/四轮未满足 5 秒耗时检查。优化后最终两次打开耗时分别为 1,982ms、2,144ms。中间通过日志不是最终源码验收依据，最终入口见 verification.json.finalValidation。
