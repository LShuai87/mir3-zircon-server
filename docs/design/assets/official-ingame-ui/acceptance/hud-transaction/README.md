# HUD 统一安装与回退

基准采用用户确认的 1024×768，继续使用既有截图和显示设置。血魔球、功能按钮、七项属性读数和经验条加入角色、包裹、快捷栏、小地图的同一安装与回退事务，共八个布局参与者。较宽分辨率下保持 1024 像素 HUD 整体居中。

原按钮事件、属性值控件、16 个装备格、49 个包裹格、10 个快捷栏链接保留。属性值前新增防御、魔防、攻击、魔法、道术、准确、敏捷标题；快捷栏开关以“栏”标识。新 HUD 根控件显式启用图像绘制，并保持原场景控件的相对层级。完整保存原按钮子标签几何，安装失败或卸载时恢复。

验证通过：7,825 项真实控件集成检查、650 项 HUD 检查、5 项角色绑定合同测试、六种分辨率的独立合同逐项比较、11 项错误合同拒绝；Debug/Release 构建、目录和源码格式检查通过。候选包未变，仍为 91 帧。

聊天容器尚未加入本次事务；现有聊天标签、历史、草稿、焦点和 HWND 保持。两张既有 GPU 探针仅验证装备槽旧图形抑制，不能代替完整 HUD 或实机验收。Legacy 默认、RuntimeReady=false、五项 G0 和任务状态保持。

修改前快照见 [before.json](before.json)，八项源码哈希迁移和成功命令见 [verification.json](verification.json)。失败调试日志保留，不计入通过结果。下一步接入聊天外框和独立输入行，再处理启动回退与设备 Reset。
